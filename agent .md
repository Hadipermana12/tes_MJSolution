# Instruksi Konteks Proyek: Signage Control Panel

AI Agent wajib merujuk pada file `PRD.md` di direktori root untuk setiap pembuatan kode, struktur komponen, maupun skema database. Pastikan implementasi mencakup:
1. Skema Supabase untuk tabel `devices` dan `contents`.
2. Implementasi WebSocket server untuk update status real-time tanpa refresh.
3. Struktur REST API CRUD dan halaman Device Client sesuai ketentuan dokumen PRD.
